# MatrixVPS

Repositório de controle de patches aprovados do Matrix.

Este repositório **não deve conter senhas, tokens, chaves SSH ou arquivos `.env`**.

Fluxo previsto:

`ChatGPT -> GitHub -> n8n -> VPS`

Os scripts aprovados ficam em `ops/approved/` e são executados pelo dispatcher instalado na VPS somente por ações permitidas.
